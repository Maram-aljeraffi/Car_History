منصة تاريخ وتوقع أسعار السيارات (Car History & Price Prediction)
تطبيق ويب ذكي ومنصة متكاملة لإدارة بيانات السيارات وتحليلها، تجمع بين قوة قواعد بيانات Oracle APEX وتقنيات التعلم الآلي (Machine Learning) للتنبؤ بأسعار المركبات بدقة بناءً على البيانات التاريخية.

✨ المميزات الرئيسية
التحليلات التنبؤية: استخدام نماذج متقدمة للتعلم الآلي (مثل Random Forest ونماذج الانحدار) لتقدير وتوقع أسعار السيارات بدقة عالية.

إدارة البيانات عبر Oracle APEX: تخزين وإدارة البيانات الكبيرة للسيارات وعملياتها بكفاءة عالية باستخدام بنية Oracle DB و Oracle APEX.

لوحة تحكم تفاعلية: واجهة مستخدم سلسة تتيح للمستخدمين إدخال مواصفات السيارة والحصول على تقديرات فورية وسريعة.

🛠️ التقنيات والأدوات المستخدمة
قواعد البيانات الخلفية: Oracle APEX, Oracle Database

لغة البرمجة: بايثون (Python)

الخلفية / واجهة البرمجة: Flask

التعلم الآلي: Scikit-Learn, Pandas, NumPy

التخزين ومعالجة البيانات: ملفات البيانات (CSV) وتخزين النماذج المدربة (.pkl)
